# Glyph Field design pass

Use Stageshow's craft and framing principles on the live application. This is a functioning image studio, not a simulated product illustration: preserve real labels, controls, keyboard behavior, the offline renderer, and complete uncropped artwork.

- Place: desktop workspace and a narrow Codex browser / phone column.
- Focal object: the generated artwork. Fit the complete composition in the available desktop height.
- Action: generate, adjust, compare, export. Keep generate and export together in a persistent toolbar.
- Payoff: a new image appears immediately; recent compositions remain easy to revisit.
- Omit: decorative masthead icon, introductory slogan, numbered section prefixes, redundant status dots, radial backdrop, oversized spacing, and tiny captions.
- Reference: Stageshow `dark-hero` for neutral surface steps, restrained accent, coherent spacing, and a distinct compact layout. Retain existing functional HTML controls rather than adopting simulated React scene components.
- Desktop: independently scrolling inspector; fitted artwork and history always visible.
- Compact: artwork first, toolbar always visible, full-width controls below, touch-sized buttons.
